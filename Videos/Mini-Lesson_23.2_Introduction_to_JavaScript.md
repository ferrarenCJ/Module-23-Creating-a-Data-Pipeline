# What is JavaScript?

JavaScript is a:

- Lightweight
- Interpreted
- Dynamically typed
- Event-driven

programming language primarily used for client-side web development.

Unlike static web pages that only display content, JavaScript allows pages to respond to user actions such as:

- Mouse clicks
- Form submissions
- Navigation events
- Keyboard input
- Dynamic content updates

Without JavaScript:

```text
Web Page = Mostly Static
```

With JavaScript:

```text
Web Page = Interactive + Dynamic
```

Today, almost every website uses JavaScript.

---

# Client-Side Web Development

JavaScript typically runs inside a web browser.

This is known as:

```text
Client-Side Execution
```

The browser downloads:

```text
HTML
CSS
JavaScript
```

and executes the JavaScript locally on the user's machine.

### Examples

JavaScript can:

- Show and hide content
- Validate forms
- Update page content
- Create charts
- Load data dynamically
- Manipulate HTML elements

---

# JavaScript and the DOM

One reason JavaScript is so powerful is its ability to control:

## Document Object Model (DOM)

The DOM represents an HTML page as a hierarchical tree structure.

Example:

```html
<body>
    <h1>Hello</h1>
    <p>Welcome</p>
</body>
```

DOM Visualization:

```text
BODY
├── H1
└── P
```

JavaScript can interact with any DOM element.

Example:

```javascript
document.getElementById("welcome")
```

This allows JavaScript to:

- Read page content
- Modify page content
- Create new elements
- Delete existing elements
- Respond to user actions

---

# JavaScript Characteristics

## Dynamically Typed

Variables can hold different data types over time.

Example:

```javascript
var value = 10;

value = "Hello";
```

No explicit type declaration is required.

---

## Case-Sensitive

JavaScript distinguishes between uppercase and lowercase characters.

Example:

```javascript
myVariable
MyVariable
MYVARIABLE
```

These are all considered different identifiers.

---

## Lightweight

JavaScript is considered lightweight because:

- Variable types do not need declarations.
- The syntax is relatively simple.
- It is easy to embed within web pages.

---

## Designed for Event Handling

JavaScript was specifically designed to handle events.

Examples:

- Click events
- Hover events
- Scroll events
- Keyboard events

Example:

```javascript
button.onclick = function() {
    alert("Button clicked!");
};
```

---

## Interpreter-Centered

JavaScript code is interpreted by the browser.

Workflow:

```text
Source Code
      ↓
Browser Interpreter
      ↓
Execution
```

Unlike languages such as Java or C++, JavaScript generally does not require a separate compilation step.

# Global vs Local Variables

JavaScript supports variable scope concepts similar to Python.

---

## Global Variable

Declared outside a function.

```javascript
var Name = "Apple";
```

Can be accessed anywhere in the script.

---

## Local Variable

Declared inside a function.

```javascript
function MyFunction() {
    var num = 45;
}
```

Can only be used inside that function.

---

# Scope Example

```javascript
<script>

// Global variable
var Name = "Apple";

function MyFunction() {

    // Local variable
    var num = 45;

    document.writeln(Name);
    document.writeln("<br>" + num);
}

MyFunction();

</script>
```

### Output

```text
Apple
45
```
